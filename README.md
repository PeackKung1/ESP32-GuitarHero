# จอยกีตาร์ไร้สายด้วย ESP32

โปรเจกต์จอยกีตาร์ไร้สายที่ใช้ ESP32 ส่งปุ่มควบคุมไปยังคอมพิวเตอร์ผ่าน Bluetooth LE Gamepad

## ความสามารถ

- ปุ่มเฟรตกีตาร์ 5 สี: เขียว แดง เหลือง น้ำเงิน และส้ม
- ปุ่มดีด 2 ปุ่ม: ดีดขึ้นและดีดลง
- คันโยก (Slide Potentiometer) ทำงานแบบปุ่ม: โยก = กด, ปล่อย = ปล่อย
- เชื่อมต่อคอมพิวเตอร์ผ่าน Bluetooth LE (ไม่ใช่ Bluetooth Classic)
- แสดงสถานะปุ่มและค่าคันโยกทาง Serial Monitor สำหรับตรวจสอบ

## อุปกรณ์

- ESP32 Dev Module
- สวิตช์ปุ่มกีตาร์ 5 ปุ่ม
- ปุ่มดีด 2 ปุ่ม
- Slide Potentiometer
- สายไฟและแหล่งจ่ายไฟสำหรับ ESP32

## การต่อวงจร

| อุปกรณ์ | ขา ESP32 | ปุ่มจอย |
|---|---:|---:|
| ปุ่มเขียว | GPIO 23 | 1 |
| ปุ่มแดง | GPIO 25 | 2 |
| ปุ่มเหลือง | GPIO 27 | 3 |
| ปุ่มน้ำเงิน | GPIO 26 | 4 |
| ปุ่มส้ม | GPIO 33 | 5 |
| ปุ่มดีดขึ้น | GPIO 17 | 6 |
| ปุ่มดีดลง | GPIO 16 | 7 |
| ขากลางของ Slide Potentiometer | GPIO 34 | 8 |
| สายดำ Common ของสวิตช์ | GPIO 32 | - |

- **สวิตช์:** ขาหนึ่งของแต่ละปุ่มต่อเข้า GPIO ตามตาราง อีกขาหนึ่งรวมกันเป็นสายดำ Common ต่อเข้า GPIO 32 โค้ดสั่ง GPIO 32 เป็น `LOW` เพื่อใช้แทนกราวด์ และตั้งขาปุ่มเป็น `INPUT_PULLUP` จึงไม่ต้องต่อตัวต้านทานเพิ่ม
- **Slide Potentiometer:** ขาด้านข้างต่อกับ 3.3V และ GND ขากลางต่อเข้า GPIO 34

> ใช้แรงดัน 3.3V กับขา ESP32 ห้ามป้อน 5V เข้า GPIO

## การติดตั้งและอัปโหลด

โปรเจกต์นี้ใช้ VS Code และ PlatformIO

1. ติดตั้งส่วนขยาย PlatformIO IDE ใน VS Code
2. เปิดโปรเจกต์และตรวจสอบไฟล์ `platformio.ini` แก้ `upload_port` และ `monitor_port` ให้ตรงกับพอร์ตของบอร์ด (ค่าเริ่มต้นคือ `/dev/ttyUSB0`)
3. กด **Build** เพื่อตรวจสอบโค้ด
4. เชื่อมต่อ ESP32 แล้วกด **Upload**

ตัวอย่างส่วนตั้งค่าใน `platformio.ini`:

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino

lib_deps =
    https://github.com/lemmingDev/ESP32-BLE-Gamepad.git
    h2zero/NimBLE-Arduino
```

## การเชื่อมต่อกับคอมพิวเตอร์

หลังอัปโหลดโค้ด ให้เปิด Bluetooth ในคอมพิวเตอร์และจับคู่กับอุปกรณ์ชื่อ **Guitar Controller** จากนั้นเลือกจอยในเกมและตั้งค่าปุ่มให้ตรงกับการควบคุมของเกม

คอมพิวเตอร์ต้องรองรับ Bluetooth LE (Bluetooth 4.0 ขึ้นไป) อะแดปเตอร์ที่รองรับเฉพาะ Bluetooth Classic จะมองไม่เห็นอุปกรณ์

## การทำงานของโค้ด

โค้ดทั้งหมดอยู่ใน `src/main.cpp`

- **ปุ่ม:** อ่านค่าทุกรอบของลูป และยอมรับสถานะใหม่เมื่อค่านิ่งครบ 25 ms เพื่อกันหน้าสัมผัสเด้ง (debounce)
- **คันโยก:** ค่าที่อ่านได้อยู่ราว 2900 ตอนปล่อย และ 3200 ตอนโยกสุด ถือว่ากดเมื่อค่าสูงกว่าตำแหน่งปล่อยเกิน 150 และถือว่าปล่อยเมื่อส่วนต่างลดลงเหลือไม่เกิน 90
- **ตำแหน่งปล่อยของคันโยก:** เลื่อนตามไฟเลี้ยง โค้ดจึงปรับตามค่าที่อ่านได้ตลอดเวลาแทนการใช้ค่าตายตัว และถ้าอยู่ในสถานะกดค้างเกิน 8 วินาที จะตั้งตำแหน่งปล่อยใหม่เป็นค่าปัจจุบัน
- **การส่งข้อมูล:** ส่งสถานะปุ่มไปคอมพิวเตอร์ทุก 20 ms เฉพาะตอนที่ Bluetooth เชื่อมต่ออยู่
- **Brownout Detector:** ถูกปิดไว้ เพราะไฟตกชั่วขณะตอนเริ่ม Bluetooth ทำให้บอร์ดรีบูตวน

### ค่าที่ปรับได้

| ค่าคงที่ | ค่าเริ่มต้น | ความหมาย |
|---|---:|---|
| `DEBOUNCE_MS` | 25 | เวลาที่ค่าต้องนิ่งก่อนเปลี่ยนสถานะ (ms) |
| `REPORT_INTERVAL_MS` | 20 | ระยะห่างการส่งข้อมูลไปคอมพิวเตอร์ (ms) |
| `POT_PRESS_DELTA` | 150 | ส่วนต่างจากตำแหน่งปล่อยที่ถือว่ากด |
| `POT_RELEASE_DELTA` | 90 | ส่วนต่างจากตำแหน่งปล่อยที่ถือว่าปล่อย |
| `POT_MAX_HOLD_MS` | 8000 | กดค้างนานกว่านี้จะตั้งตำแหน่งปล่อยใหม่ (ms) |

## การตรวจสอบผ่าน Serial Monitor

เปิด Serial Monitor ที่ความเร็ว 115200 จะเห็นข้อมูลดังนี้

- ค่าคันโยกและตำแหน่งปล่อยปัจจุบัน ทุก 200 ms
- สถานะการเชื่อมต่อ Bluetooth
- ข้อความแจ้งเมื่อมีการกดหรือปล่อยปุ่ม พร้อมชื่อปุ่มและหมายเลข GPIO (แสดงเฉพาะตอนที่ Bluetooth เชื่อมต่ออยู่)

ถ้าคันโยกกดไม่ติดหรือติดเอง ให้ดูค่าที่พิมพ์ออกมาตอนปล่อยและตอนโยกสุด แล้วปรับ `POT_PRESS_DELTA` กับ `POT_RELEASE_DELTA` ให้เหมาะกับช่วงค่านั้น
